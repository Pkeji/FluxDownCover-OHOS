## 二、反编译差距分析结果（对照 0.4.7/0.4.8 i18n 全量 1698 键）

### 2.1 可本地移植 — 本轮已完成 ✅
见上表全部条目（RSS 增强 / 下载策略 / BT 设置 / 队列高级 / 详情信息 / TXT 导入 / 系统主题 / 多终端）。

### 2.2 已在前轮完成 ✅
搜索与筛选、自定义分类、任务管理（重命名/移动/重新检查/清理/批量）、队列（限速/定时）、完成通知、做种控制、HLS 清晰度、剪贴板监听、全局代理/UA/GitHub 镜像、多线程/断点续传/完整性校验、公共目录导出、MCP 本地服务、10 色主题。

### 2.3 依赖外部生态，不可移植 ⛔（明确跳过）
| 组 | 原因 |
|---|---|
| `account*`（账户/云同步/套餐/推荐/设备/邮箱） | 需 FluxCloud 服务端 |
| `plugin*` / `market*` / `components*`（yt-dlp/FFmpeg 插件市场） | 二进制插件生态 |
| `multiDevice*` / `device*` / `localPairing*` / `dispatch*` | 跨设备协同服务端 |
| `extension*` / `doctor` / `fromBrowserExtension` | 浏览器扩展（独立 WXT 工程） |
| `tray*` / `floatingBall` / `closeToTray` / `autoStartup` / `titlebarButtons` / `sidebarVisibility` / `viewColumns` / `viewDensity` / `viewForm` / `viewGroup` / `viewSort` / `revealFileCmd` / `shutdown*` / `donate*` | 桌面/窗口系统专属能力 |
| `changelog*` / `updateChannel` | 官方更新通道（本工程为独立实现，已在关于页提供检查更新） |

### 2.4 可移植但价值/成本比低，暂未移植（候选）
| 组 | 说明 |
|---|---|
| `webhook*`（ntfy/Bark/Discord 等推送） | 本地 HTTP 可实现，需事件订阅+签名，可下轮加 |
| `settingsSearch*` | 设置项搜索，纯 UI 增强 |

| `dynamicSplit*`（动态拆分） | 现为固定分段，可升级为下载中动态补段 |
| 多任务右键菜单（原桌面版） | 移动端已用滑动/长按替代 |
